# Codex Prompt - Premium Frontend

Read AGENTS.md, docs/08-frontend-design-system.md, and docs/17-frontend-pages-and-wireframes.md fully before coding.

Build the premium KisanPath frontend using the established API contracts.

Prioritize:
- mobile-first voice assistant;
- refined dark premium visual foundation;
- excellent Gujarati/Hindi typography;
- signature voice orb with accessible motion states;
- elegant profile confirmation chips/cards;
- premium scheme recommendation cards;
- clear evidence drawer;
- polished loading, empty, offline, and error states;
- keyboard/screen-reader accessibility;
- reduced-motion support.

Avoid generic dashboard templates, cartoon agriculture graphics, excessive green gradients, and decorative animation.

Implement the landing page, assistant page, recommendation result flow, evidence detail, and judge/demo evaluation screen. Use realistic seeded content where backend data is not yet available, but keep data access behind typed client interfaces so mocks can be removed cleanly.
